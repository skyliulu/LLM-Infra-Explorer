## 2026-09-11 用户要求的结构重做

用户明确否定五种机制平铺切换，授权改为自顶向下钻取。本节覆盖下面初版页面结构方案。沿用原数值模型、来源追踪及回归，重新组织信息架构，不再把同一层内的分支作为互斥方案。

- 默认入口是 V4-Flash 宏观图：Embedding → 前两层 SWA → 20组 CSA/HCA 交替层 → 第43层 CSA → final norm / LM head。左侧模型上下文持续可见，右侧展开放大的 attention 单元。
- [官方配置](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash/blob/main/config.json) 的 num_hidden_layers=43，compress_ratios 前43项为0/0/4/128/.../4；额外第44项为MTP，不画成主干第44层。维度4096、64个query头、head_dim512、index_head_dim128、index_n_heads64、Top-K512、窗口128。
- 同层数据流：输入hidden分别形成main query、局部KV及全局压缩/索引状态；CSA全局分支用indexer选择，HCA读取全部已完成压缩项；全局与局部共同进入attention，随后输出投影，并经mHC/MoE所在的block上下文传给下层。层间连的是hidden，不是前层KV送入后层压缩器。
- 点选具体层（独立 layer 输入，1–43）→ 点分支/节点（focus受该层结构约束）→ 点缓存项/通道。面包屑与返回保留上下文。默认仅显示宏观和层内图，参数/缓存/索引/公式在选中对应节点后出现；不再把旧页面全量铺在架构图后面。
- DSA不画成V4里的独立串联模块。在CSA indexer节点说明选择思想的沿用，入口可跳到独立的全量/DSA比较；只有两种真正替代的方案使用比较切换。

- 能力新增data-movement；不增加timeline。重点验证从宏观→层→分支→条目再返回，选HCA移除索引器但保留SWA，局部分支不把全层切成SWA，参数联动仍来自同一快照。初版所有模式与尺寸的截图/检查沿用作改版前基线，本轮追加桌面CSA基线截图。

## 教学问题与能力

同一段历史，哪些位置仍被保存、当前 query 实际读取哪些表示？先比较全量与 DSA，再比较 SWA、V4 CSA + SWA、HCA + SWA。

能力：multiple-modes、resource-metrics、structural-comparison、dense-layout、math。采用结构选择、参数扫描、来源放大；不引入播放时间轴。画面是单层、单请求、当前 token 已写入后的因果快照，改变长度相当于查看另一快照，不表示每个 decode 重新压缩所有历史。

## 控制与耦合

- mode：互斥模式；改变全局/局部缓存、索引器、读取集合、公式和伪代码。
- tokens：1–64 的独立整数输入，包含当前位置；压缩项仅在整个组可见时发布。
- query：两组固定教学 query；仅改变 indexer 分数、Top-K、主 attention 权重和输出，不改变任何缓存内容。
- topK：1/2/4/8，限 DSA/CSA；实际数量为请求值与可见项数的较小值。
- window：4/8/16，限 SWA/CSA/HCA；各模式共享输入。
- CSA ratio：2/4/8，HCA ratio：8/16，各自独立。缩小尺寸用于让稀疏选择可见，不冒充 V4 实际超参数。
- inspect：全局项编号，越界钳位；channel：0/1，观察压缩器按通道不同的权重。
- language：仅展示偏好。重置恢复领域默认值，保留语言。
