## 读完后独立复述

DeepInfer 的服务效率来自几个不同层次。共享 KV 让重复前缀免于每次重算，少做有效输入工作；Decode 用更大的专家并行组汇集 Token、把专家权重分得更细，使一次权重读取服务更多 Token。专家副本重分配降低最忙卡的尾部等待，内核和通信融合再减少每份工作的开销。Prefill 与 Decode 按不同流量需求分配资源，单引擎异步安排把 CPU 调度/状态更新与 GPU 工作重叠，减少设备空隙。它们共同提高符合延迟要求的有效吞吐，因此能在给定总小时成本下压低单位 Token 成本。

这个结果不保证迁移到任意负载：缓存命中少仍要付存储成本；Wide-EP 依赖高速互联、路由和足够负载；无前后批次就没有异步重叠收益。官方每 GPU 每小时 38 美元是其生产服务收入，不能当引擎速度、利润或一月回本承诺。实际回收投入还取决于收入、运行支出和初始投入。

复述依据全部来自本次实际页面：缓存计数、EP2/EP8 对照、热点工作/等待条、同步异步时间图、总成本/有效吞吐公式及收入敏感性实验。即使去掉最详细的请求调度动画，前述性能与成本解释仍成立；章节没有被局部调度演示取代。
