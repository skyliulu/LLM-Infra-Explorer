# DeepInfer 独立结果验收

2026-10-28。验收者先制定 `outcome-review-criteria.md`，再读取新实现、官方资料并用独立 Edge 标签实际操作开发预览 `http://127.0.0.1:5173/#deepinfer`。未修改实现与 Skill；不采用上一轮 QA 结论作为通过依据。

## 阶段性结论

当前性能/成本版本已回答本轮核心问题，内容和已实际抽查的交互未发现剩余 P0/P1/P2。**这里是开发预览的独立验收；最终生产构建与全矩阵尚需另行复核，不把抽查扩大成全部通过。**

读者现在可以形成完整解释：缓存复用减少重复输入计算；更大的专家并行组把权重分得更细、汇入更多 Token，从而提高权重复用；热点专家放置会影响最慢卡；融合内核/低精度改变每份工作自身的成本；分阶段配置与异步执行分别减少服务级和引擎内等待。它们共同影响延迟约束下的有效服务量，而不是无条件相乘的几个加速倍数。

这一版把原来请求生命周期/ZOS 作为下层机制保留，不再把它当全部性能来源。DSpark、CED、量化等解释在框架中的作用，再指向已有专题，没有把所有内部算法平铺进主页面。K/R/C 的经济测算是独立情景，不擅自从教学图推算真实收入。

## 发现与修复

- **P2，已关闭：Wide-EP 的因果机制原先仍是结论。** 首个版本只写“减少权重访存”，交互仅展示 EPLB 最慢卡，官方曲线也只能显示结果。经反馈新增同样 8 卡、32 Token、8 逻辑专家的 EP2/EP8 结构交互，显示组数、每卡权重、每权重服务 Token、总读取份数的变化。现在其收益来源可以从图上解释，关闭该缺口。
- **P3，已关闭：教学路由假设不完整。** 现在明确每个 Token 只路由一个专家，并声明等大专家、均匀路由、每步一次读取、无额外副本。这不是实测 HBM 或速度比。
- **P3，已关闭：经济公式变量需猜测。** 已给 K/R/C 对应的初始投入、小时收入和小时运行支出。
- **P3，已关闭：回本说明含作者审阅口吻。** “官方已读取的资料”改为 README/问答公布收入、没有承诺一月回本，中文更自然。
- 主实现者自行修正了架构入口/返回箭头、负载条的固定时间轴与完成线；验收者在实际新版中看到手机入口落向 Prefill，16 固定轴上平衡批次结束于 9，不能再把整条灰底误读成等待至 16。
- 验收者曾在 Dark→Light 的首张过渡截图看到暗节点/深色文字，随后稳定截图和 computed style 显示白底。该报告已当场撤回，不将过渡帧记成持续主题缺陷。

## 实际独立执行

使用 Edge 独立配置，不与主 agent 的 IAB 矩阵共享语言/主题偏好。

| 操作 | 实际观察 | 判断 |
|---|---|---|
| 缓存比例 100% / 0% | 仍需处理 0 / 1000，基线一直 1000 | 与示意输入位置计数一致；附近有真实块对齐/恢复开销的限制 |
| EP2 → EP8 | 组 4→1；组内 Token 8→32；每卡权重 4→1；每权重 Token 1→4；读取总份 32→8 | 同样设备、输入和逻辑专家，结构/指标同步，说明权重复用而非宣称实际 4 倍速度 |
| 热点重分配关闭/开启 | 最慢卡 16→9，总工作量始终 32，等待条与完成线改变 | 解释额外副本/重分配缓解热点与其代价 |
| 流量改为新输入多 | 资源份额 Prefill 2→6，Decode 6→2 | 是独立配置示意，明确不是八张物理卡或吞吐模拟 |
| 收入比例 0%，小时支出 $8 | 小时收入0，日净现金−192，无有限回收期 | 负现金流边界正确 |
| 收入比例100%，小时支出 $50 | 小时收入38，日净现金−288，无有限回收期 | 不把收入当利润；收入不足时不显示伪回本日期 |
| ZH→EN，切换分支 | 数值/配置保留，内容按语言变化 | 未观察到缺失 key 或错配 |
| 实际 Light/Dark | 新架构、分组、图例、数字及文本在稳定帧可读 | 抽查通过，不据此宣称全部主题矩阵覆盖 |

## 经济与证据口径

已读取官方固定版本 README、部署 Q&A，并查阅其 main 原文。页面将 155T tokens/day 和 $38/GPU-hour 放在完整线上生产服务上下文，后者为谷价收入。明确公开离线引擎仍需额外服务组件；专家组对照图保留上下文、nextn、接受率、专家副本及请求并发条件。没有把图中吞吐直接换成整套服务利润。

初始投入、支出、收入比例均标为示例；净现金不为正时没有有限回收期。30 天条件作为所需净现金展示，没有认定“一月回本”为官方承诺。模型不计融资、税费、残值，页面作了说明。这些是教学情景，不是硬件采购或投资收益建议。
