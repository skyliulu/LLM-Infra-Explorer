# DeepInfer：层级、章节分工与中文验收

2026-10-28。用户反馈上一轮虽补充了技术细节，却把框架讲解做成了特性清单；代码库研究也没有回答原理与章节侧重问题。本轮按 `principles.md` 重构。旧 depth trial 保留为历史，不作为新布局的验收。

## 最终结果

- 新建 `analyze-technical-principles`，默认先分析问题、设计思路、职责分层和章节归属。Codebase Knowledge Builder 退出默认流程，保留为实际源码研究时的可选工具。
- 页面有真实的服务 → 引擎 → 设备执行三级关系。引擎讲请求队列、批次调度、设备执行、结果与状态；执行层将每层 Attention/MoE 与最终采样分开。父层返回保留包含原组件的分支，键盘也能下钻。
- 移除本章独立的 DSpark 验证预算、MoE 精度探针、KV 字节实验和十一项平铺特性导航。已有推测解码章节负责候选/验证原理；DeepInfer 说明验证结果如何接回引擎。EPLB 在专家执行上下文解释负载作用，不宣称并行章节已有完整 EPLB 教程。
- 保留并修好框架自身的请求推进和异步依赖实验。中文改为具体对象和动作，代码默认折叠，版本信息移到资料区。先修只保留生成流程与 KV 基础，专题算法为可选深入。
- 分享只包含场景、Prefill 预算和异步设置。旧链接中的已移除实验字段会被忽略。

## 实际验收

最终 production build、DeepInfer model、13章 workbench、theme compiler、conventions 均通过；两个 Skill 的官方 validator 通过。层级模型检查父子关系、路径、选中回退和专题归属；原有 612 个轨迹快照、18组配置、10组依赖安排继续通过。静态职责关系由资料/实现和拓扑检查核实，不为架构图虚构性能数字。

浏览器实际走了跨级返回、逐级返回、键盘下钻、组件说明、真实专题链接、Home 往返、三字段分享及完整重载、普通重载、采样/状态更新、末帧/自动停止/重置和时间图选中。Spec Decode 的 DSpark 实验已实际打开，检查后恢复进入前的算法选择。旧参数没有通过导航重新出现。Console 警告/错误记录为空。

外观覆盖 service/engine/execution × 1440/768/390 × 中文/英文 × Light/Dark，共36个唯一组合；另有12张手机说明近景、4张调度/部分输入回归、4张时间图和2张时间图尾部。独立 reviewer 逐张目视58张，主作者操作真实浏览器并检查主预览。最后只修改了时间图选中描边的主题颜色，相关修复与手机尾部又作了局部独立复核；最终截图已刷新。未发现剩余 P0–P2，发现的 P3 描边问题也已关闭。

System 在当前环境解析为 dark，保留暂停进度和请求选择；另一种 OS 外观没有模拟接口，未声称覆盖。没有 GPU/NPU 推理或性能实测。

## 发现与修复

| 问题 | 处理与证据 |
|---|---|
| 用户：层级和侧重被特性数量取代 | 新原理 Skill、章节职责表、三层下钻与可选专题链接；浏览器确认本章三个重复算法实验已不存在。 |
| 用户：中文生硬、过程术语多 | 重写主叙述、阶段、请求说明和时间图文案；按实际选择和阶段连读，而非只检查键名。 |
| H1 P2：安排请求时已声称完成部分计算 | 新增 requestScheduled，区分选中待算与已算未完成；A step1/B step2模型断言和明暗截图通过。 |
| H2 P3：跨两级返回丢失原分支 | 面包屑用 parent trail 的下一项选择包含原视图的组件；实际 execution→service 保持 engine 选中。 |
| H3 P3：最终采样说明混入前置预算调度 | 改为用主模型结果检验候选并反馈实际接受长度；层内/最终采样关系与实现核对。 |
| P3：深色选中描边不明显 | 使用显式 light-dark 配色；实际 dark 为 rgb(147,197,253)，light 为 rgb(15,23,42)，局部截图复核关闭。 |

独立 Skill 行为评估见 `docs/audits/skill-autonomy/principles-focus-eval.md`：vLLM 框架与 FlashAttention 算法两种请求分别处理，避免把“分工”误解为少讲算法自己的核心机制。该评估是决策 dry run，不是新章节 E2E。

## 结果范围

本章完整性以框架组织问题和职责表判断，不以覆盖全部研究条目判断。生产服务与公开离线引擎仍区分；示例缩小条件与假设时间保留；具体模型算法在专题展开。新原理 Skill 的通用效果还需要未来案例检验，本轮不声称一个案例能保证所有主题一次成功。
