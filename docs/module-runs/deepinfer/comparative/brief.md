# 站内体验对照后的设计修正

2026-11-13，用户再次指出视觉、交互、信息组织、密度和教学友好度不足。当前任务继续修改 DeepInfer，不重建相邻章节，不推送/发布。前轮 connected 的通过不再适用；独立基线也明确不通过。

## 实际对照

同一浏览器/语言/外观下打开 CED、Sparse、Flash 和 DeepInfer。CED 首屏将症状、资源账本和对应机制连起来；点击矩阵后对象与输入/变换/输出同屏。Sparse 默认展示同输入的两条真实矩阵路径，形状、操作和 IO 变化紧邻对象。Flash 的资源条和 HBM/片上相同 tile 身份直接接时间泳道。不是每章都完美，也不应复制它们的卡片数或数值。

旧 DeepInfer 的主要问题：架构图约 751px 高且多为空框；实际专家实验起点约在文档 1648px；文章式窄栏、同色表面、先读指标再找对象；主图点选→说明→另一个按钮跳转；内核两套24格状态需要读者脑内还原并发。截图证明存在内容，不能证明这种体验达到本站标准。

## 选择与合同

保留连续论证和同一系统边界，改为“结果锚点→三种工作量变化→紧凑系统图/同屏职责→连续机制”。不使用互斥特性页吞掉默认论证，不引入新图形框架：DOM、CSS定位轨道和原生语义按钮足以表达固定拓扑、条形时间、状态检查和键盘操作。

首屏新增官方64请求工作点（明确双轴单位、约数、副本差异）及与共享配置相连的历史/专家/交接缩略图；按钮一步定位机制。系统图缩小空白，并排职责检查器，不用额外跳转才能读出作用。蓝色输入、绿色历史、紫色专家、黄色等待分别表达对象/状态关系。

专家图先呈现物理副本和输入行；直接点击任意一侧的权重选择同一逻辑专家，指标在对象之后。EP2四组按2×2排，输入行示意通道，保持具体T身份。内核以同一0–12尺度显示A/B/C轨迹，点选任一路径/块，单一检查器展开生产消费依赖；用户播放/暂停/步进/重播，结束和卸载停止。缓存横向3FS→主机→HBM，后缀另行；调度四卡初值只画一次，两方案只展示接收卡变化。

技术内容、计算模型、来源边界沿用固定DeepInfer/DeepGEMM提交，不添加新性能或回本宣称。仍解释P/D、EP批量、融合依赖、共享历史、时间quota、双维负载与完整费用/有效输出关系。CED、投机解码等算法保留原章节所有权。

## 本轮验收的区别

先对照本站真实体验，再检查重构后的完整阅读。独立审阅必须能指出相对于原版/邻章的具体可见改善，也能拒绝机械通过；owner仍需冻结后从首屏读至页尾。最终核验新物理对象点选、两路径块身份、播放退出/终点、状态共享、双语/明暗/三屏宽与当前OS的System解析。72张旧截图不能作为新版本证据。手机允许堆叠，不能靠缩小所有字号来实现密度。
